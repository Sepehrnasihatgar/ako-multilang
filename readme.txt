Link your pages across languages — hreflang, RTL and a language switcher, without changing your URLs.

== Description ==

Cedar Multilang connects pages you already have in different languages. It does not translate content and it does not change your URLs.

* Link any post, page or custom post type to its translations.
* Correct hreflang tags with x-default, and the right `lang` and `dir` on every page.
* Right-to-left languages switch the site direction automatically.
* An accessible language switcher as a block, shortcode or menu item.
* Imports existing pairs from Cedar Multilang 6.2.

Cedar Multilang makes no external requests and collects no data.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install it from the Plugins screen.
2. Activate it.
3. Go to Cedar → Languages and add your languages.

== Frequently Asked Questions ==

= Does it translate my content? =

No. It links pages you already wrote in each language.

= Does it change my URLs? =

No. Every page keeps its address.
